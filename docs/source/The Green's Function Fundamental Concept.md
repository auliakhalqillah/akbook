## Green's Function in Seismology

A Green's Function (GF) is one of the fundamental concepts in seismology. It describes the impulse response of an elastic medium to a point source excitation, representing how seismic waves propagate from a specified source location to a recording station. In this context, the Green's Function characterizes the Earth's response to an impulsive seismic source, considering the physical properties and structural configuration of the medium between the source and receiver.

Mathematically, the recorded ground motion can be described through the convolution of the earthquake source-time function and the corresponding Green's Function. For an earthquake represented by a moment tensor, the displacement field is generally expressed as the temporal convolution between the time-dependent moment tensor and the spatial derivatives of the Green's tensor. The Green's Function describes the wave propagation effects, including geometrical spreading, intrinsic attenuation, scattering, reflection, refraction, mode conversion, and local site effects, depending on the complexity of the Earth model used in its calculation.

Unlike a point-source approximation, a large earthquake involves rupture propagation over a finite fault surface with a specific length and width. The rupture process evolves spatially and temporally, meaning that different portions of the fault generate seismic waves at different locations and times. To represent this complexity, the fault plane is discretized into a grid of smaller elements, commonly referred to as subfaults. Each subfault is assigned its own source parameters, including slip amplitude, rupture initiation time, and source-time function.

The Green's Function is calculated for each subfault-to-station configuration to represent the corresponding seismic wave propagation response. The resulting synthetic ground motion is obtained by convolving the source-time history of each subfault with its corresponding Green's Function and subsequently summing the contributions from all subfaults. This approach provides a mathematical framework for simulating the complete ground-motion time series generated by a finite earthquake rupture.

Furthermore, Green's Functions can be obtained either theoretically, through analytical or numerical wave propagation simulations using an Earth model, or empirically, using observed records from smaller earthquakes. The latter approach is known as the Empirical Green's Function (EGF) method, in which appropriately selected small-earthquake records are used to approximate the propagation response for modeling larger earthquakes, subject to appropriate source and path similarity assumptions.
